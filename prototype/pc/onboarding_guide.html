阶段 0签约与开户（服务商侧）

商务签约落定后，服务商在企业管理系统一键开户，系统自动完成账号初始化。

开户动作

商务签约（营运类型 / 套餐 / 合同期）
新增企业 → 自动创建企业主账号用户名=企业全称
企业主账号初始密码888888
默认子账号：安全员 / 驾驶员已预置

信息录入与开通

营业执照上传 · OCR 智能识别填充法人/有效期
补全联系人、运输类型、客户分组
配置合同期、功能模块开通范围

阶段 1资料采集（自助填报 + 代录）

两类方式并行：懂系统的客户用小程序三步自助填报；不会用的客户由服务商代录（上传照片 + 复用历史签字直接生成）。采集完成前，小程序仅显示接入引导，业务功能锁定。
📋 诊断前置：采集第三步「安全管理现状」通过选择题快速判断客户底子（制度/人员/台账/三检/培训/隐患）。客户往往正是因为原有资料不规范、不齐全，才产生与我们签约的意愿——诊断结果直接驱动下一阶段「静态资料全面整改」。

小程序三步自助填报

① 企业基础资料（营业执照拍照）进度①
② 人档 + 车档（姓名/手机号/岗位/车牌）进度②
③ 安全管理现状（选择题 + 自由描述）待提交

服务商代录（不会用的客户）

服务商代填企业/人车资料
复用企业历史签字，打印手签兜底
提交后 PC 端实时查看三块资料

阶段 2静态资料全面整改（核心价值）

依据监管要求，结合该企业实际的安全管理架构，由服务商全面整改 / 新建以下静态资料——既要满足法规检查，也要贴合企业真实运行情况（而非千篇一律的模板套话）。
🛠️ 为什么是这一步？客户签约的核心诉求就是「把原来不规范、不齐全、应付不了检查的资料，整改成合规且可用的体系」。以下六类资料，构成企业安全生产管理的静态骨架，缺一类都会被监管检查或事故溯源追责。

① 安全管理架构

安全管理组织架构图已归档
成立安全生产领导小组的通知已归档
安全生产管理人员任命书已归档

安全生产操作规程 / 风险评价手册范本生成

综合应急预案已归档

阶段 3小程序全员账号开通（自动化）

人员录入即开通，无需单独建号。不同岗位按自身职责，在小程序端看到不同的功能。
开通规则（自动执行）
  • 录入人员信息（姓名 / 手机号 / 岗位）时，所有岗位自动开通小程序端账号；
  • 小程序登录账号 = 人员手机号，初始密码 = 123456；
  • 不同岗位根据其职责显示不同功能（见下表），权限与 PC 端组织权限同源；
  • 人员离职 / 停用 → 小程序账号同步停用，人档车档保留 ≥ 3 年；启用后账号恢复。
岗位（职责）小程序端可见功能
驾驶员 / 押运员一日三检、行车日志、报修车、报隐患、签文件（责任书/承诺书）、查考核、学习中心（视频+答题）
安全员 / 安全管理人员督办隐患、证件到期提醒、三检统计、下发任务、安全数据看板、会议管理、人员管理
企业管理员全部管理功能 + 企业安全管理驾驶舱（数据总览 / 预警 / 待办）

阶段 4制度台账归档就位

范本管理定制 / 推送至企业 → 企业按清单签署 → 电子档案柜 11 盒归档，盒内按文件夹分组，缺项红黄绿一目了然，可一键下载整套台账 PDF。

阶段 5日常运营（持续闭环）

资料就位后进入常态化运营，各模块持续产生数据并闭环：

日常业务

一日三检（司机每日出车前后）
安全会议（季度/月度四段式留痕）
培训教育（课程库选课→看视频+答题）
隐患排查治理（上报-整改-验收）

合规与年审

动态监控合规闭环（台账留存→违规→靶向教育）
应急管理（预案+演练+器材）
事故管理（快报+统计）
自然年度重签 + 年审续费
一句话回顾新企业接入：签约开户（自动建企业主账号 888888）→ 资料采集（小程序自助 / 服务商代录，先诊断后整改）→ 静态资料全面整改（架构 / 24 项制度 / 预案 / 各类计划 / 三书 / 岗前培训，既合规又贴合实际）→ 小程序全员自动开通（手机号登录、初始密码 123456、按岗位显功能）→ 制度台账 11 盒归档自检 → 进入日常运营闭环。
