## 一、模块定位

安全投入是"**合规提取 + 支出留痕**"环节——国家要求运输企业**必须按营业收入的一定比例提取并使用安全生产费用**（专款专用）。政府检查要看的就三样：**营收证明、提取标准及计划、使用台账**。

**核心定位**：
- **收集上年度营业收入** → 系统**自动计提**当年安全费用（普货 1%、危货 1.5%）。
- **提供表单按费用类别登记支出** → 自动形成**使用台账**（含发票/收据）。

> 设计逻辑：安全投入 = **一个数字（营收）+ 一个比例（计提）+ 一张表（支出台账）**。系统把"该提多少钱"算出来、把"钱花哪了"记下来，政府检查一键出盒。

## 三、核心模型

### 3.1 计提模型（B1/B2/B3）

```
上年度营业收入（企业录入）
        ×
计提比例（普货 1% / 危货 1.5%，按营运类型自动匹配）
        =
当年应提安全费用（系统自动计算）
```

| 营运类型 | 计提比例 |
|---------|---------|
| 普货（道路普通货物运输） | 1% |
| 危货（道路危险货物运输） | 1.5% |

> 依据《企业安全生产费用提取和使用管理办法》，普货按营业收入 1%、危货按 1.5% 提取（比例可配置，若法规调整由超管改字典）。

### 3.2 支出台账模型（B4/B5/B6）

> 费用类别采用《企业安全生产费用提取和使用管理办法》（**财资〔2022〕136 号**）规定的 11 类标准支出范围（线下台账实测口径）。**政府检查按此 11 类对账**，故系统预置这 11 类 + 允许企业增补"其他"。

| # | 费用类别（预置，code） | 说明 |
|---|----------------------|------|
| 1 | 安全防护设施设备支出 | 完善、改造和维护安全防护设施设备（不含"三同时"要求初期投入的安全设施），含运输设施设备和装卸工具安全状况检测及维护系统、附属安全设备等 |
| 2 | 车辆定位监控装置支出 | 购置、安装和使用具有行驶记录功能的车辆卫星定位装置、视频监控装置等 |
| 3 | 应急救援器材及演练支出 | 配备、维护、保养应急救援器材、设备支出和应急救援队伍建设、应急预案制修订与应急演练支出 |
| 4 | 危险源监控与隐患整改支出 | 重大危险源检测、评估、监控支出，安全风险分级管控和事故隐患排查整改支出，安全生产信息化、智能化建设、运维和网络安全支出 |
| 5 | 安全检查评价咨询支出 | 安全生产检查、评价（不含新建改扩建项目安全评价）、咨询和标准化建设支出 |
| 6 | 安全防护用品支出 | 配备和更新现场作业人员安全防护用品支出 |
| 7 | 安全宣传教育培训支出 | 安全生产宣传、教育、培训和从业人员发现并报告事故隐患的奖励支出 |
| 8 | 新技术新装备推广支出 | 安全生产适用的新技术、新标准、新工艺、新装备的推广应用支出 |
| 9 | 设施检测检验支出 | 安全设施及特种设备检测检验、检定校准支出 |
| 10 | 安全责任保险支出 | 安全生产责任保险及承运人责任保险支出 |
| 11 | 其他安全生产支出 | 其他与安全生产直接相关的支出 |

> 每笔支出 = 日期 + 费用类别（11 类）+ 事由 + 金额 + 发票/收据。系统自动汇总成使用台账（横向 11 类 × 12 月，见 5.2）。

> 注：财资〔2022〕136 号原文含"铁路和城市轨道交通防灾监测预警设备支出"等铁路专属项，**道路运输企业不适用**，故系统只预置上述 11 类。

## 四、数据模型（DDL）

### 4.1 安全投入主表 budget_plan（B1/B2/B3，年度计提）

```sql
CREATE TABLE budget_plan (
  id              BIGINT PRIMARY KEY,
  tenant_id       BIGINT NOT NULL,
  year            INT NOT NULL,                 -- 计提年度
  cargo_type      VARCHAR(10),                  -- general普货/danger危货
  revenue         DECIMAL(14,2),                -- 上年度营业收入（元）
  revenue_file    VARCHAR(500),                 -- 营收证明文件（B7）
  rate            DECIMAL(5,4),                 -- 计提比例（普货0.01/危货0.015，B2）
  plan_amount     DECIMAL(14,2),                -- 应提金额 = revenue × rate（B3）
  used_amount     DECIMAL(14,2) DEFAULT 0,      -- 已用金额（支出台账汇总）
  balance         DECIMAL(14,2),                -- 结余 = plan_amount - used_amount
  status          VARCHAR(20) DEFAULT 'draft',  -- draft/confirmed
  created_by      BIGINT,
  created_at      DATETIME DEFAULT NOW(),
  updated_at      DATETIME,
  deleted         TINYINT DEFAULT 0
);
```

> `plan_amount = revenue × rate` 系统自动算；`used_amount` 由支出台账实时汇总；`balance` 展示使用进度。

### 4.2 费用类别字典 budget_category（B5）

```sql
CREATE TABLE budget_category (
  id              BIGINT PRIMARY KEY,
  tenant_id       BIGINT NOT NULL DEFAULT 0,    -- 0=系统预置，>0=企业自定义
  category_name   VARCHAR(100) NOT NULL,        -- 费用类别名（财资136号11类全称）
  category_code   VARCHAR(50),                  -- 编码（FACILITY/LOCATION/RESCUE/HAZARD/CHECK/PPE/TRAIN/TECH/INSPECT/INSUR/OTHER）
  sort_order      INT,
  created_at      DATETIME DEFAULT NOW(),
  deleted         TINYINT DEFAULT 0
);
```

> 系统预置 11 类（见 3.2），`tenant_id=0`；企业自定义类别 `tenant_id>0`。预置类别 `deleted` 不可置 1（保证政府对账口径稳定）。

### 4.3 支出台账表 budget_expense（B4/B6）

```sql
CREATE TABLE budget_expense (
  id              BIGINT PRIMARY KEY,
  tenant_id       BIGINT NOT NULL,
  plan_id         BIGINT NOT NULL,              -- 关联年度计提
  category_id     BIGINT,                       -- 费用类别（B5）
  expense_date    DATE NOT NULL,                -- 支出日期
  expense_desc    VARCHAR(500),                 -- 事由/摘要
  amount          DECIMAL(12,2) NOT NULL,       -- 金额（元）
  receipt_file    VARCHAR(500),                 -- 发票/收据（B6）
  created_by      BIGINT,
  created_at      DATETIME DEFAULT NOW(),
  updated_at      DATETIME,
  deleted         TINYINT DEFAULT 0
);
```

> 每笔支出登记后，`budget_plan.used_amount` 实时汇总，`balance` 实时更新。

### 4.4 归档映射（B12）

> 档案盒「盒五·安全生产费用提取与使用」3 个子项：

| 归档子项 | 数据来源 |
|---------|---------|
| 年度营收入证明 | `budget_plan.revenue` + `revenue_file` |
| 安全费用提取标准及计划 | `budget_plan`（营收 + 比例 + 应提金额） |
| 安全生产费用使用台账（发票或收据） | `budget_expense`（按类别汇总 + 凭证） |

> 模板 `TPL_BUDGET`，页眉企业全称 + 盒号 + 归档项 + 时间 + 二维码，自动盖章。

## 五、核心流程

### 5.1 计提流程（B1/B2/B3/B7）

```
① 企业录入上年度营业收入 + 上传营收证明
② 系统按营运类型自动匹配比例（普货1%/危货1.5%）
③ 自动计算当年应提安全费用 = 营收 × 比例
④ 生成「安全费用提取标准及计划」（自动盖章）
```

### 5.2 支出登记流程（B4/B6/B8）

```
① 选择费用类别（预置11类/自定义"其他"）
② 填写支出日期 + 事由 + 金额 + 上传发票/收据
③ 系统实时汇总已用金额 + 结余
④ 提示达标情况（未足额使用/超提提醒）
```

> **使用台账结构（对齐线下）**：支出台账 PDF 按「横向 11 类费用 × 纵向 12 月」矩阵汇总，另附逐笔支出明细（日期/类别/事由/金额/凭证）。线下实测为 1 张 xlsx 内含 12 个月 Sheet + 1 个横向汇总 Sheet，系统生成 PDF 时输出同等版式。

### 5.3 归档流程（B12）

```
① 营收证明 + 提取标准计划 + 使用台账 三要素齐备
② 一键生成盒五全部资料 PDF（自动盖章）
```

## 六、业务规则

1. **计提基数上年度**：当年应提 = 上年度营业收入 × 比例（B1/B3）。
2. **比例随营运类型**：普货 1%、危货 1.5%，自动匹配，可配置（B2）。
3. **支出按类别登记**：系统预置财资136号 11 类，企业可增补"其他"（B4/B5）。
4. **每笔支出留凭证**：上传发票/收据（B6）。
5. **营收需证明**：录入营收同时上传营收证明（B7）。
6. **达标校验**：提示支出 vs 应提对比，未足额/超提提醒（B8）。
7. **盖章**：台账自动盖公司章（B10）。
8. **数据可改日志不改**：超管可改安全投入数据，操作日志不可改（B11）。

## 七、页面交互设计

### 7.1 PC 端（管理端，核心）

**计提页**：
- 年度列表（按年）
- 「新增计提」：录入上年度营收 + 上传营收证明 → 自动算应提金额
- 展示：营收、比例、应提金额、已用、结余

**支出登记页**：
- 支出台账列表（按类别/日期筛选）
- 「登记支出」：类别 + 日期 + 事由 + 金额 + 发票上传
- 达标提示（未足额/超提）

### 7.2 小程序

无需（安全投入为管理岗操作，司机不涉及）。

## 十、开发任务拆解

1. 年度计提表 + 自动计算（营收 × 比例）
2. 计提比例配置（普货 1%/危货 1.5%，可改）
3. 费用类别字典（预置 + 自定义）
4. 支出台账登记表单（类别 + 凭证上传）
5. 已用/结余实时汇总
6. 达标校验提示（未足额/超提）
7. 归档对接 08（模板 `TPL_BUDGET`）

## 十一、验收标准

1. 录入上年度营业收入 + 营收证明后，系统按普货 1%/危货 1.5% 自动计算应提金额。
2. 支出可按预置/自定义类别登记，每笔上传发票/收据。
3. 已用金额、结余实时汇总更新。
4. 系统提示达标情况（未足额使用/超提）。
5. 归档可生成盒五全部资料 PDF（营收证明 + 提取标准计划 + 使用台账，带盖章）。
