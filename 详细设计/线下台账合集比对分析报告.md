# 线下台账合集比对分析报告

> 分析对象：用户上传的《台账合集.zip》（线下版本，82 个文件，覆盖 12 个档案盒）
> 用途：用真实企业线下成品，校验我方 20 个模块详细设计 + 档案盒归档设计，找出差异点并给出修正建议。
>
> **核心结论**：线下台账印证了我方"变量化范本引擎 + 档案盒归档"的整体设计方向完全正确，但暴露出 **4 处需要修正的细节**（费用类别口径、告知书全称、任命书编号字段、会议三段式结构），详见下文。

## 二、重大印证：线下台账本身就是"范本引擎"产物

这是我方设计正确性的**最直接证据**。线下多个 docx 里残留了**未替换的变量占位符**：

| 线下文件 | 残留变量 | 说明 |
|---|---|---|
| 安全生产责任书（车队长） | `{{companyName}}`、`{{staffSign}}` | 公司名 + 员工签名 |
| 制度目录 | `{{companyName}}` | 公司名 |
| 教育培训计划通知 | `{{companyName}}` | 公司名 |
| 安全费用提取计划 | `{{seal}}`、`{{companyName}}`、`{{startDate}}` | 印章 + 公司名 + 日期 |
| 应急演练计划 | `{{companyName}}` | 公司名 |

**含义**：线下企业实际用的就是一套"变量填充"生成台账的工具（可能是某软件或人工套模板），占位符没替换干净就打印了。这**完全印证**我方 09《静态资料范本引擎》的 `{{变量}}` 机制——我们的设计不是凭空发明，而是把线下已经在做的事**系统化、规范化**，且保证"变量必填、不残留占位符"。

## 三、需修正的 4 处细节

### 修正 1：安全费用支出类别 → 采用财资〔2022〕136 号 11 类标准口径 ⚠️

**现状**：我方 17《安全投入》预置费用类别是笼统的 6 类（安全设施设备/教育培训/应急救援/隐患排查/劳保用品/保险）。

**线下实际**：支出统计台账、预算计划书都严格按《企业安全生产费用提取和使用管理办法》（财资〔2022〕136 号）的 **11 个标准支出范围**横向列示：

| 序号 | 标准支出范围（线下台账原文） |
|---|---|
| 1 | 完善、改造和维护安全防护设施设备支出（不含"三同时"要求初期投入的安全设施） |
| 2 | 购置、安装和使用具有行驶记录功能的车辆卫星定位装置、视频监控装置等支出 |
| 3 | 配备、维护、保养应急救援器材、设备支出和应急救援队伍建设、应急预案制修订与应急演练支出 |
| 4 | 开展重大危险源检测、评估、监控支出，安全风险分级管控和事故隐患排查整改支出，安全生产信息化、智能化建设、运维和网络安全支出 |
| 5 | 安全生产检查、评价（不含新建改扩建项目安全评价）、咨询和标准化建设支出 |
| 6 | 配备和更新现场作业人员安全防护用品支出 |
| 7 | 安全生产宣传、教育、培训和从业人员发现并报告事故隐患的奖励支出 |
| 8 | 安全生产适用的新技术、新标准、新工艺、新装备的推广应用支出 |
| 9 | 安全设施及特种设备检测检验、检定校准支出 |
| 10 | 安全生产责任保险及承运人责任保险支出 |
| 11 | 其他与安全生产直接相关的支出 |

**修正动作**：`budget_category` 的预置类别改为上述 11 类（+ 允许企业增补"其他"），并在 17 文档标注依据"财资〔2022〕136 号"。

> 附：线下"计提计划"里出现了 12 条（多了"铁路和城市轨道交通防灾监测预警设备支出"），那是铁路企业专属，**道路运输企业不适用**，我方只需 11 类。

### 修正 2：岗位危害告知书全称 → "岗位职业病危害因素告知书"

**现状**：我方 07/09 文档用名"岗位危害告知书"。

**线下实际**：文件名与正文标题均为"**岗位职业病危害因素告知书**"，且正文引《职业病防治法》，含"岗位危害（久坐类：前列腺疾病、颈腰椎病、脂肪肝、视力下降、手腕酸痛）+ 防治措施 + 告知人/被告知人签字"三段。

**修正动作**：归档项名称统一为"岗位职业病危害因素告知书"，范本正文补全"危害因素 + 防治措施 + 双签"结构。

### 修正 3：任命书增加"文件编号"字段

**现状**：我方任命书范本无编号字段。

**线下实际**：任命书含"文件头（公司名 + 文件编号）+ 正文 + 生效日期 + 盖章"结构，例如：
- 安全生产管理人员任命书：文件编号 `-66675208915`、生效日期
- 监控人员任命书：文件编号 `0-17780`、生效日期（正文为"任命 XX 同志为公司**兼职**监控人员"）

**修正动作**：任命书范本增加"文件编号"（可复用文档编号池，与领导小组通知的 `doc_no` 同源）和"生效日期"字段。同时注意线下任命书区分"**专职**安全生产管理人员"与"**兼职**监控人员"两种表述。

### 修正 4：会议记录采用"通知 + 签到 + 记录 + 照片"四段式（印证，非修正）

**现状**：我方 12《安全会议》已设计会议通知、签到、记录。

**线下实际**：单个会议文件内按顺序包含 4 段：
1. **会议通知**（会议时间/地点/内容/参会人员）
2. **签到表**（会议时间/参会人数/主持人 + 序号/姓名/岗位/签名表，岗位列含"安全管理员、监控员、总经理、车队长、驾驶员"）
3. **会议记录**（会议名称/地点/时间/主持人/记录人/会议议题/会议记录正文）
4. **会议照片**（附于表后）

**结论**：我方设计方向正确，但需确认"签到表岗位列顺序"与线下一致（安全管理员→监控员→总经理→车队长→驾驶员），且会议纪要需含"议题"字段。

## 四、岗位清单印证（无修正）

线下台账明确出现 5 个岗位：**总经理（主要负责人）、安全员（安全管理员）、监控员、车队长、驾驶员**。

我方 06《组织架构》岗位清单已包含"车队长"（标注"非强制（有则填）"），**无需修正**。但需注意两点：

| 观察 | 结论 |
|---|---|
| 线下"车队长"职责里混入了大量动态监控职责（第 9-13 条） | 说明部分小微企业"车队长"兼任监控，但**监控员有独立任命书**，岗位仍是分开的 |
| 线下责任书岗位有"总经理、安全员、监控员、车队长、驾驶员"5 种，无"押运员/装卸/调度/停车场" | 因为这是**普货企业**；危货企业才会有押运员/装卸管理员等 |

## 五、各盒格式要点速查（供后续范本细化参考）

| 盒 | 关键格式要点 |
|---|---|
| 盒一 | 任命书（文件编号+生效日期）、责任书（目标+职责，含 `{{companyName}}` 占位）、承诺书、告知书（职业病三要素）、领导小组通知（文号+组长/副组长/成员+职责）、二级维护计划 |
| 盒二 | 制度编号 ZD01~ZD22（22 项）+ 操作规程 + 风险辨识手册；目录页含 `{{companyName}}` |
| 盒三 | 会议四段式（通知/签到/记录/照片）；签到岗位列顺序固定 |
| 盒四 | 年度培训计划（通知 + 计划表：序号/类别/时间/内容/对象/学时/方式/培训人） |
| 盒五 | 计提计划（财资136号 + 11类范围 + 营收×1%）+ 支出台账（**按月分 12 个 Sheet + 汇总 Sheet 横向 11 类×12 月**）+ 预算计划书 |
| 盒六 | 动态监控管理制度（框架版） |
| 盒七 | 应急预案（风险评估报告+资源调查报告+预案+论证记录）+ 演练计划（序号/预案名/时间/方式/目的/组织部门/物资）+ 应急值班表（值班领导/值班人员签名） |
| 盒八 | 隐患排查（序号/项目类别[重大事故隐患项+基础管理]/检查项目/检查内容与标准/检查结果/备注）+ 风险辨识（全面清单 + 分级管控清单） |
| 一人一档 | 岗前试卷（单选/多选/判断，含"答题人答案/正确答案"） |

## 六、后续建议

1. **落地 4 处修正**（费用 11 类、告知书全称、任命书编号、会议四段式确认），更新 17/07/09/12 四个文档。

3. **隐患排查"重大事故隐患项"清单**（特殊天气/企业资质/三超一疲劳/车辆运输/车辆改装）是政府重点检查项，可固化为我方 13 文档的预置排查项模板。
4. **风险辨识两级清单**（全面清单 → 分级管控清单，后者多"风险源/事故后果/控制措施[工程+管理]"）与我方 18《风险辨识》模板设计对齐确认。
