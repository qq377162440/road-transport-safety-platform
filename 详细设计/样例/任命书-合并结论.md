# 任命书范本合并样例 - 说明（增减型典型）

> 配套文件：`样例/任命书-范本合并样例.html`
> 日期：2026-10-27

---

## 一、为什么任命书适合合并（增减型）

5 份任命书（主要负责人/安全员/监控员/驾驶员/财务）结构高度一致：

```
关于任命 [岗位] 的通知
公司[全体人员/各部门及全体人员]：
[任命正文：任命 [人名] 为 [岗位]，职责描述一句话]
特此通知。
公司：[企业名]
[生效日期/日期]
```

岗位间差异**只有 3 处**，且都是"增减/替换个别词"，不是"整段结构变化"：

| 差异点 | 说明 | 处理方式 |
|--------|------|---------|
| 标题前缀 | 安全员/监控员带公司名前缀，其他不带 | `{{title_prefix}}` 条件变量 |
| 抬头 | "全体人员" vs "各部门及全体人员" | `{{dept_scope}}` 变量 |
| 任命正文 | 人名、岗位名、职责描述一句话不同 | `{{appoint_intro}}` 整段变量 |

> 关键：任命书的**职责描述是一句话**，用"整段变量 `{{appoint_intro}}`"就能承载，而不是像责任书那样"整段 10~21 条职责"。这就是"增减型"和"替换型"的本质区别。

## 二、与责任书样例的对比结论

| | 责任书（替换型） | 任命书（增减型） |
|--|----------------|----------------|
| 岗位差异 | 整段职责 + 签订关系 + 签字结构都不同 | 仅人名/岗位名/一句话职责 |
| 是否合并 | ❌ 保留独立范本 | ✅ 合并为单范本 |
| 变量类型 | 需要大量 `{% if %}` 条件段落 | 仅几个 `{{变量}}` + 整段变量 |

## 三、给范本改造的判定规则（最终版）

改造任何一类范本时，先问一个问题：

> **这个范本的岗位间差异，是"换几个词"，还是"换整块内容 + 换结构"？**

- 换几个词（人名/岗位名/一句话）→ **增减型** → 合并单范本，用 `{{变量}}`
- 换整块内容 + 换结构（整段职责/签字栏/签订关系）→ **替换型** → 独立范本

**实操判据**：把两个岗位的范本并排看，如果"删除 A 的职责段、粘贴 B 的职责段"就能变成 B，那就是替换型；如果"把 A 里的名字改成 B 的名字、把岗位词替换"就能变成 B，那就是增减型。

## 四、结论

方案 B'（分层）的判定规则已通过两个样例验证：

- **责任书、承诺书** → 替换型 → 独立范本
- **任命书、告知书** → 增减型 → 合并范本

这个规则将作为后续所有范本（盒二~盒十一）改造的统一标准。
