# 范本系统化改造验证说明

> 本文档是「范本/原型验证」阶段的产出说明，配套两个交互式原型样例：
> - `成立安全生产领导小组通知-范本改造样例.html`
> - `复工复产六个一套装-范本改造样例.html`
>
> 目的：验证 09《静态资料范本引擎》设计的**变量化机制**（`{{变量}}` + 列表变量 + 条件段 + 一键签名）能否把用户最终确认的两份纸质范本，改造成可被系统调用的、按企业数据自动填充的台账范本。

---

## 一、验证结论（先看结论）

| 验证项 | 结论 |
|---|---|
| 变量化改造可行性 | ✅ 两份范本均可 100% 变量化，无需逐字录入 |
| 数据自动带出 | ✅ 企业名称、组长/副组长/成员、文号、日期均可从既有模块自动带出 |
| 一键签名/盖章 | ✅ 主要负责人签名、企业公章均可自动套用（复用 09 文档 8.1 全局能力） |
| 联动生成 | ✅ "六个一"7 份文件共用同一组变量，一次录入联动生成 |
| 仍需企业补齐 | ⚠️ 现场照片、签到表签名、培训试卷作答、检查记录表勾选——这些是"过程留痕"，必须现场产生，系统只能留空占位 |

## 二、范本一：成立安全生产领导小组的通知

### 2.1 变量清单与数据来源

| 变量名 | 数据来源 | 类型 | 示例值 |
|---|---|---|---|
| `company_name` | 03 企业信息（tenant） | 单值 | 佛山市励硕物流有限公司 |
| `doc_no_prefix` | 企业简称（tenant.short_name） | 单值 | LSWL |
| `doc_no` | 自动生成：`{前缀}通知【{年度}】{序号}号` | 组合 | LSWL通知【2025】21号 |
| `leader_name` | 06 组织架构·主要负责人 | 单值 | 万君 |
| `deputy_names` | 06 组织架构·安全员 | 列表 | 夏倩君 |
| `member_names` | 06 组织架构·其余人员 | 列表 | 宋传雨、万良俊、梅霞、高如飞、杨涛 |
| `sign_date` | 系统时间 | 单值 | 2025-10-09 |
| 领导小组职责（11条） | 系统内置固定文本 | 常量 | —— |

### 2.2 关键改造点

1. **文号自动生成**：`doc_no` 不再由企业手填，而由系统按「企业简称 + 文种 + 年度 + 序号」规则从文档编号池自动递增。
2. **成员自动带出**：组长 = 主要负责人（06 模块）、副组长 = 安全员、成员 = 组织架构中其余安全管理相关岗位人员。企业无需重复录入姓名。
3. **职责固定内置**：11 条职责是《安全生产法》规定的法定职责，作为系统级常量内置，不随企业变化，降低范本维护成本。

## 三、范本二：复工复产"六个一"套装

### 3.1 套装结构（7 份文件）

| 序号 | 文件 | 变量填充 | 企业补齐 |
|---|---|---|---|
| ① | 安全生产诚信承诺书 | 企业名 + 盖章 + 法代签名 | 法代手签 |
| ② | 领导班子安全生产专题会议 | 企业名 + 日期 + 地点 + 授课人 | 现场照片 + 签到表 |
| ③ | 节后复工复产方案 | 企业名 + 复工领导小组 + 日期 | —— |
| ④ | 全体员工大会 | 企业名 + 日期 + 地点 + 授课人 | 现场照片 + 签到表 |
| ⑤ | 全体员工安全培训教育 | 企业名 + 日期 + 地点 + 授课人 | 现场照片 + 签到表 + 试卷作答 |
| ⑥ | 应急方案 | 企业名 + 应急领导小组 + 应急电话 + 日期 | —— |
| ⑦ | 节后复产安全检查记录表 | 企业名 + 日期 | 检查项目勾选 + 签名 + 整改记录 |

### 3.2 共用变量（一次录入，7 份联动）

| 变量名 | 数据来源 | 说明 |
|---|---|---|
| `company_name` | 03 企业信息 | 贯穿 7 份 |
| `leader_name` / `deputy_names` / `member_names` | 复工领导小组（默认复用安全生产领导小组） | ②③⑥ 三份引用 |
| `resume_date` | 节后首个工作日（自动取） | 贯穿培训/会议/检查时间 |
| `place` / `teacher` | 企业填写 | ②④⑤ 引用 |
| `tel` | 企业信息·应急电话 | ⑥ 引用 |

### 3.3 关键改造点

1. **范本组（一套）联动**：7 份文件不再是 7 个独立文件，而是 1 个范本组，共用同一组变量；企业首次配置完企业信息 + 复工领导小组后，一键生成全套。
2. **"六个一"与"高危行业六个一"的差异**：范本内置了常规"六个一"（道路运输普货/危货适用），高危行业"三个一→六个一"的解读文案在②专题会议中作为固定条款内置。
3. **过程留痕需现场补齐**：照片、签到、试卷作答、检查勾选属"过程证据"，无法预生成，系统只打印占位框（照片框、签到表空表、□是□否勾选框），由企业复工后补充上传，符合 15 应急管理"企业补齐照片+签到即完成"的思路。

## 五、后续建议（待确认）

1. **范本组归属**：确认"六个一"套装是作为盒一单独范本组，还是并入既有"复产复工"范本分类。
2. **文号编号池**：确认文号序号的年度重置规则（跨年是否从 1 号重新计）。
3. **高危行业差异**：若未来服务危货企业，是否需要单独维护"高危行业六个一"文案版本（当前范本已内含解读，可共用）。
