## 一、结论先行

1. **用户明确了制度范本的最终形态**：普货、危货各有一套"全区域通用版"，不是按区域细分。之前的"乐从区域通用版"其实是**同一套普货范本的不同表述**，区域差异只体现在企业名称、地址、人员等**变量**上，不构成独立范本组。
2. **应急预预案纳入制度生成**：用户要求"制度生成顺便把企业的应急预案也生成了"。应急预案是**独立的第三类制度文件**，且按**车辆类型细分**（冷链车版已给，后续还有罐车、厢式等）。
3. **危货不需要我们出应急预案**：危货应急预案由客户自备（危货有专门的第三方安全评价/应急预案备案流程）。
4. **普货 vs 危货制度结构差异明确**：13 项共有 + 普货 10 项独有 + 危货 8 项独有，差异集中在"危货特有的押运、装卸管理、停车场地、专用车辆、查验记录"等。

### 2.3 应急预案（冷链车版，独立文件）

**多篇结构**，含 3 大部分：

| 篇章 | 内容 |
|------|------|
| 总则篇 | 编制目的/依据/适用范围/响应分级/预案体系 |
| 专项预案篇 | ①道路交通事故 ②车辆火灾 ③恶劣天气（3 个专项） |
| 现场处置方案篇 | ①车辆碰撞 ②车辆起火 ③车辆涉水坠水 ④**冷藏机组故障/温控失效** ⑤人员伤亡 ⑥办公场所火灾（6 个处置方案） |

## 三、普货 vs 危货 制度差异（核心）

### 3.1 共有制度（13 项）

| 制度 | 说明 |
|------|------|
| 安全生产责任制 | 结构一致，岗位数不同（普货 10 岗 / 危货 12 岗） |
| 安全生产监督检查制度 | 内容高度一致 |
| 安全生产教育培训制度 | 危货多"押运员、装卸管理人员"培训 |
| 安全生产考核与奖惩制度 | 结构一致 |
| 安全生产费用提取和使用管理制度 | 一致（危货提取比例更高） |
| 安全事故报告、统计与处理制度 | 危货多"危险货物泄漏事故"报告 |
| 动态监控管理制度 | 一致 |
| 劳动保护用品配备和使用管理制度 | 危货多"防毒面具、防腐蚀"用品 |
| 消防安全管理制度 | 危货多"防爆"要求 |
| 安全生产会议制度 | 一致 |
| 隐患排查与治理制度 | 一致 |
| 重大危险源管理制度 | 危货更严格（危险货物临界量） |
| 安全生产台账及档案管理制度 | 危货多"危险货物运单、查验记录"台账 |

### 3.2 普货独有（10 项）

|------|-------------|

## 四、岗位结构差异（验证"两层结构"）

### 4.1 普货 10 岗位

总经理、安全部经理、安全管理员、车队长、驾驶员、（调度）、监控员、财务部经理、（办公室）、技术员

### 4.2 危货 12 岗位

总经理、分管安全副总经理、安全管理员、运营调度员、车队长、驾驶员、监控室负责人、办公室、财务、**危险货物运输押运人员**、**车辆技术管理员**、**停车场管理员**

> **印证**：危货在普货基础上，新增了 **押运人员、车辆技术管理员、停车场管理员** 3 个危货特有岗位。这与文档 06《组织架构.md》中用户定稿的"危货岗位"完全一致。

### 4.3 危货操作规程的 10 类（印证"两层结构"）

1. 驾驶人员安全生产操作规程
2. 押运人员安全生产操作规程
3. 装卸管理人员安全操作规程
4. 危险货物运输操作规程
5. 危险货物运输车辆动态监控操作规程
6. 车辆的组织调度操作规程
7. 安全防护用品穿戴操作规程
8. 危险品车辆罐体清洗消毒操作规程
9. 车辆各级维护操作规程
10. 车辆安全检查和检测操作规程

> **印证结论**：危货操作规程确实是**按"作业环节/岗位"分层**（驾驶/押运/装卸/监控/调度/清洗/维护/检测），而不是按"危险货物类别（易燃/腐蚀/毒害）"分层。**用户之前定稿的"危货两层结构（车辆结构 × 危险货物类别）"中，"危险货物类别"这一层在实际范本里并没有独立成篇**，而是以"运输特定类别危险货物时，还应检查相关附加装备"这种**条件性条款**散落在操作规程里。

> **待决策点 E（重要修正）**：危货操作规程是否需要"按危险货物类别（易燃/腐蚀/毒害/爆炸/放射性）"进一步细分？从实际范本看，**不需要**——危货范本已经是"岗位环节"分层，货物类别的差异用"条件性附加条款"处理（如"运输易燃易爆品应 X 时前完成""酸碱接触岗位戴面罩"）。建议把文档 09 的"危货两层结构"修正为：**第一层 = 车辆结构（罐式/厢式/集装箱/气瓶），第二层 = 作业环节/岗位（10 类规程），危险货物类别降级为"条件性附加条款"**。

## 五、应急预预案的定位（新增模块）

### 5.1 应急预案是独立制度文件

用户要求"制度生成顺便把应急预案也生成了"。应急预案与 14 项制度不同，它是：

| 维度 | 制度 | 应急预案 |
|------|------|---------|
| 生成粒度 | 普货一套 / 危货一套 | **按车辆类型一套**（冷链车版、罐车版、厢式版...） |
| 结构 | 单篇 | **多篇**（总则 + 专项预案 + 现场处置方案 + 附件） |
| 变量 | 企业信息 + 岗位 | 企业信息 + 岗位 + **车辆类型专项** + 应急资源 |
| 危货 | 我们出 | **客户自备**（不归我们） |

### 5.2 应急预案的拼装逻辑

应急预案的"车辆类型差异"体现在**现场处置方案**层面：

| 车辆类型 | 独有现场处置方案 |
|---------|----------------|
| 冷链车 | 冷藏机组故障、货物温控失效 |
| 罐车 | （待用户提供）罐体泄漏、介质危险 |
| 厢式 | （通用） |
| 气瓶 | （待用户提供）气瓶泄漏 |

> **建议**：应急预案范本采用"**通用骨架 + 车型专项**"结构——总则、专项预案、人员伤亡/办公火灾等通用处置方案是公共部分，车型特有的处置方案（如冷链温控失效）按车辆类型挂载。

### 5.3 待确认的应急预案车辆类型清单

目前只有冷链车版。需要用户提供其余车型的应急预案范本，或明确哪些车型共用一套：

- 冷链车（已有）
- 罐车/槽罐车？
- 厢式货车？
- 栏板/仓栅？
- 其他？

## 六、范本引擎设计的更新（本次新增/修正）

### 6.1 新增"应急预案"范本类型

文档 09 的范本分类需新增：

| 范本类型 | 说明 | 生成方式 |
|---------|------|---------|
| 制度范本 | 14 项制度 | 普货/危货各一套 |
| 规程范本 | 操作规程 | 普货 1 类 / 危货 10 类 |
| **应急预案范本** | 多篇结构 | **按车辆类型** |

### 6.2 修正"危货两层结构"

文档 09 原定义：危货两层 = 车辆结构 × 危险货物类别。

**修正为**：危货两层 = 车辆结构（罐式/厢式/集装箱/气瓶）× 作业环节/岗位（10 类规程），危险货物类别降级为"条件性附加条款"。

### 6.3 区域维度的最终定性

用户已明确"全区域通用版"，之前的"乐从区域版"是同一套范本。**区域不是范本维度**，区域差异（企业名/地址/人员）全部是变量。决策点 B 关闭。
