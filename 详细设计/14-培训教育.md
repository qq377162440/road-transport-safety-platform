## 一、模块定位

培训教育是"**日常执行**"环节的第三块（三检→会议→**培训**），对应需求文档因果链"人员/车辆合规"与"日常执行"之间——**人不培训，就会违章，违章就积累隐患，隐患就酿事故**。

**核心目标**：搭建**在线学习平台**（视频库 + 题库），从业人员在系统里真实在线看视频、真实做题考核，系统**记录观看进度/时长并留痕签字、拍照**，政府检查时一键出盒（含签字、盖章）。

**关键定位**：
- 系统**做在线学习平台**——视频库承载"教"（在线观看），题库承载"考"（在线做题），从业人员在系统内完成学习全过程。
- **学时管控做成企业可配置开关**：默认**关闭**（学时仅提示，不强制），企业可**开启**（须看完/学满才解锁考核）。选择权交给企业。
- 系统**始终留痕三件事**：**签字 + 拍照 + 考核**，加上**观看进度/时长记录**，共同构成政府检查需要的"培训台账"证据链。

> 设计逻辑：在线学习平台提供"真实学习"的能力，学时开关提供"是否强制"的灵活度。企业要宽松就默认（看完即走、随时考核），要严格就开启（学满才考）——平台负责给工具和证据，企业负责定规矩。

## 三、核心模型

### 3.1 三类培训差异总览（T1）

| 培训类型 | 编码 | 谁创建 | 视频/资料来源 | 从业人员动作 | 归档归属 |
|---------|------|--------|-------------|-------------|---------|
| 岗前培训（三级安全教育） | pre_job | 企业（安全员） | 运营方上传线下资料（可下载） | 在线看/学 + 签字 + 拍照 + 线上考核 | 一人一档（07）+ 盒四 |
| 岗中培训（年度/月度） | on_job | **服务商账号**（平台） | 运营维护的 12 个月视频（在线观看） | 在线看视频 + 签字 + 拍照 + 考核 | 盒四·月度培训 |
| 靶向培训（违规专项） | targeted | 企业（安全员） | 按违规类型**随机匹配 2 个视频（≤30分钟）** | 在线看 + 签字 + 拍照 + 考核 | 盒四·月度培训 |

> **关键职责划分**：岗中培训是**平台运营统一生产**（普货/危货两套年度课程），企业"开箱即用"；岗前/靶向是**企业自主创建**。从业人员在系统内**在线看视频 + 做题考核**，系统记录观看进度并留痕签字/拍照。

### 3.2 学时开关模型（T9，企业可配置）

> 学时要求做成**企业可配置开关**，默认关闭。学时标准本身（下表）始终存在，只是"强制与否"由开关决定。

| 身份 | 岗前总学时 | 岗中每月学时 |
|------|-----------|-------------|
| 普货从业人员 | 24 | 2 |
| 普货管理人员 | 32 | 2 |
| 危货从业人员 | 72 | 2 |
| 危货管理人员 | 48 | 2 |

| 开关状态 | 学时作用 | 观看行为 | 考核门槛 |
|---------|---------|---------|---------|
| **关闭（默认）** | 仅提示文案 | 记录观看进度/时长（留痕） | 无前置，随时可考 |
| **开启** | 强制达标 | 记录进度，须学满（看完视频/达标） | 学满才解锁考核 |

> 学时换算：1 学时 = 45 分钟（如岗中 2 学时 = 90 分钟）。开关开启时，按"累计观看时长 ≥ 学时所对应分钟数"判定达标。

### 3.3 学习 + 留痕状态机（T9/T10）

```
未开始 → 学习中（看视频，记录进度）
              ↓
        [开关开启] 学时达标 → 待考核
              ↓
        签字 + 拍照 + 考核通过 → 已完成
              ↓
        考核未通过 → 可重考（次数可配）
```

| 状态 | 含义 | 触发 |
|------|------|------|
| `not_started` 未开始 | 已绑定，未开始 | 绑定人员后 |
| `learning` 学习中 | 看视频中，记录观看进度 | 首次进入视频 |
| `qualified` 学时达标 | 学满（仅开关开启时出现） | 累计时长达标 |
| `exam_pending` 待考核 | 已解锁题库（开关开启时） | 学时达标后 |
| `completed` 已完成 | 签字 + 拍照 + 考核通过 齐备 | 三件事齐备 |
| `failed` 考核未通过 | 考核未通过，可重考 | 得分 < 及格线 |

> **开关关闭时**：跳过 `qualified`/`exam_pending`，从业人员随时可签字/拍照/考核（三件事独立）。**开关开启时**：须先学满才进入待考核。

---

### 3.4 服务商课程库（视频与考题的全局中枢，已重构）

> **定位变化**：视频库从"**按企业分别维护视频 / 卷子**"重构为"**服务商全局课程库**"——视频与考题成为服务商运营的**平级模块**，面向其名下所有企业复用，而非每家企业各维护一份。

- **课程**是核心单元：一门课程含「视频列表 + 绑定的配套卷子（考题）」，课程有名称、课时数、总时长。
- **多维筛选**：按**课程分类 / 行业分类 / 岗位分类**组合筛选（对齐 01 的 RBAC 与行业字典）。
- **卷子（考题）**：视频可绑定 / 改绑 / 解绑配套卷子；卷子有名称、内含多道试题（单选 / 多选 / 判断），学员看完视频后作答。
- **分页与运营**：课程列表支持分页（如 10 条 / 页），服务商统一维护、统一下发；企业 / 学员在「学习中心」选课学习 + 答题考核。
- **与代录 / 范本的边界**：课程库属运营配置，不随企业数据 tenant 隔离；学员的"学习 / 考核记录"才按企业 tenant 隔离（见 4.5~4.7）。

## 四、数据模型（DDL）

### 4.1 视频库表 training_video（T3/T8，在线观看）

```sql
CREATE TABLE training_video (
  id              BIGINT PRIMARY KEY,
  tenant_id       BIGINT NOT NULL DEFAULT 0,   -- 0=平台/运营级视频（岗中），>0=企业自定义
  video_name      VARCHAR(200) NOT NULL,       -- 视频名称
  video_desc      VARCHAR(2000),               -- 视频内容文字描述（对应台账"培训内容"）
  video_url       VARCHAR(500) NOT NULL,       -- 视频文件地址
  duration        INT NOT NULL,                -- 视频时长（分钟，用于学时判定/展示）
  violation_type  VARCHAR(50),                 -- 适用违规类型标签（引用违规类型字典，靶向匹配用）
  cargo_type      VARCHAR(10),                 -- 适用运输类型：general普货/danger危货/all通用（岗中）
  is_platform     TINYINT DEFAULT 0,           -- 是否平台级视频（运营维护）
  created_at      DATETIME DEFAULT NOW(),
  updated_at      DATETIME,
  deleted         TINYINT DEFAULT 0
);
```

> 视频库是**在线学习**的内容载体，从业人员在线观看，系统记录观看进度；`duration` 用于学时判定（开关开启时）和展示。

### 4.2 题库表 training_question（T4）

```sql
CREATE TABLE training_question (
  id              BIGINT PRIMARY KEY,
  tenant_id       BIGINT NOT NULL DEFAULT 0,   -- 0=平台级，>0=企业自定义
  video_id        BIGINT,                      -- 关联视频（题目针对该视频内容）
  question_type   VARCHAR(20),                 -- single单选/multi多选/judge判断
  stem            TEXT NOT NULL,               -- 题干
  options         TEXT,                        -- 选项（JSON，选择题）
  answer          VARCHAR(500),                -- 正确答案
  analysis        VARCHAR(1000),               -- 解析（可选）
  created_at      DATETIME DEFAULT NOW(),
  deleted         TINYINT DEFAULT 0
);
```

### 4.3 培训计划主表 training_plan

```sql
CREATE TABLE training_plan (
  id              BIGINT PRIMARY KEY,
  tenant_id       BIGINT NOT NULL,
  plan_name       VARCHAR(200) NOT NULL,       -- 培训计划名称
  plan_type       VARCHAR(20) NOT NULL,        -- pre_job岗前/on_job岗中/targeted靶向
  cargo_type      VARCHAR(10),                 -- general普货/danger危货（岗中年度计划用）
  year            INT,                         -- 年度（岗中：如 2026）
  month           INT,                         -- 月份（岗中：1~12，对应 12 个月）
  learn_hours     INT,                         -- 学时（提示/强制达标标准，T9，随开关生效）
  force_learn     TINYINT DEFAULT 0,           -- 学时开关：0=关闭(仅提示) 1=开启(学满才解锁考核)，企业可配（T9）
  pass_score      INT DEFAULT 60,              -- 考核及格线（分）
  max_retry       INT DEFAULT 3,               -- 最大重考次数
  learn_deadline  DATETIME,                    -- 学习截止时间（提示/强制用）
  violation_type  VARCHAR(50),                 -- 违规类型（targeted 靶向，用于匹配视频）
  attach_files    VARCHAR(2000),               -- 附件（岗前：运营方上传的线下培训资料，可下载）
  status          VARCHAR(20) DEFAULT 'draft', -- draft/published/ongoing/finished
  created_by      BIGINT,                      -- 创建人（运营/安全员）
  created_at      DATETIME DEFAULT NOW(),
  updated_at      DATETIME,
  deleted         TINYINT DEFAULT 0
);
```

### 4.4 培训计划-视频关联表 training_plan_video（T6/T7）

```sql
CREATE TABLE training_plan_video (
  id              BIGINT PRIMARY KEY,
  tenant_id       BIGINT NOT NULL,
  plan_id         BIGINT NOT NULL,
  video_id        BIGINT NOT NULL,
  month           INT,                         -- 月份（岗中：1~12，对应 12 个月）
  sort_order      INT,                         -- 排序
  created_at      DATETIME DEFAULT NOW()
);
```

> **岗中（T6）**：运营生成年度计划时，自动挂 12 个月视频（1~12 月各一段）；**靶向（T7）**：创建时按 `violation_type` 从视频库**随机抽取 2 个视频（合计时长 ≤ 30 分钟）**挂入。

### 4.5 培训人员绑定表 training_assign（观看进度 + 签字 + 拍照）

```sql
CREATE TABLE training_assign (
  id              BIGINT PRIMARY KEY,
  tenant_id       BIGINT NOT NULL,
  plan_id         BIGINT NOT NULL,             -- 关联培训计划
  user_id         BIGINT NOT NULL,             -- 被培训人员（从业人员）
  user_type       VARCHAR(20),                 -- 人员类型（驾驶员/押运员/安全管理人员/监控管理人员/主要负责人）
  status          VARCHAR(20) DEFAULT 'not_started', -- not_started/learning/qualified/exam_pending/completed/failed
  watch_minutes   INT DEFAULT 0,               -- 累计观看时长（分钟，学习留痕，T10）
  watch_progress  VARCHAR(2000),               -- 观看进度（JSON：每个视频的观看进度）
  sign_image      VARCHAR(500),                -- 培训人签名图片（T10）
  sign_time       DATETIME,                    -- 培训人签名时间
  photo           VARCHAR(500),                -- 培训人培训照片（拍照留痕，T10）
  photo_time      DATETIME,                    -- 拍照时间
  created_at      DATETIME DEFAULT NOW()
);
```

> **学习 + 留痕（T10）**：`watch_minutes`/`watch_progress`（观看进度留痕）+ `sign_image`（签字）+ `photo`（拍照）+ 考核结果（见 training_exam）。学时判定仅当 `force_learn=1` 时生效（开关开启才要求学满解锁考核）。

### 4.6 考核记录表 training_exam（T4）

```sql
CREATE TABLE training_exam (
  id              BIGINT PRIMARY KEY,
  tenant_id       BIGINT NOT NULL,
  assign_id       BIGINT NOT NULL,             -- 关联 training_assign
  user_id         BIGINT NOT NULL,
  questions       TEXT,                        -- 本次考核试题（JSON：题目+选项，快照留痕）
  answers         TEXT,                        -- 用户答案（JSON）
  score           INT,                         -- 得分
  result          VARCHAR(10),                 -- pass通过/fail未通过
  submit_time     DATETIME,                    -- 交卷时间
  created_at      DATETIME DEFAULT NOW()
);
```

> **考核留痕（T4/T11）**：`questions`（试题快照）+ `answers`（答案）+ `score/result`（结果）完整留存，对应台账"考核试题及考核结果"。

### 4.7 违规类型字典表 violation_dict（T8，只做框架）

```sql
CREATE TABLE violation_dict (
  id              BIGINT PRIMARY KEY,
  tenant_id       BIGINT NOT NULL,
  violation_name  VARCHAR(100) NOT NULL,       -- 违规类型名称（企业自定义，如"疲劳驾驶"）
  violation_code  VARCHAR(50),                 -- 编码（可选）
  created_at      DATETIME DEFAULT NOW(),

```

> **T8 只做框架不预设**：`violation_dict` 表由企业自行维护，系统不预置初始违规类型清单。

### 4.8 归档映射（T11/T15）

> 档案盒「盒四·安全生产教育和培训」三条归档项（与政府检查台账样例对应）：
> 1. **安全生产教育和培训计划**
> 2. **岗前安全教育培训记录**（三级：公司级/部门级/岗位级）
> 3. **安全生产月度培训**（岗中·学习报告：应学/已学学时+课程+考试）

由 `training_plan` + `training_assign` + `training_video` + `training_exam` 汇总生成。**培训台账完整要素（T11）**：
- 培训内容 = 视频文字描述（`video_desc`）
- 主要负责人签字 + 安全员签字（归档确认时签，T13）
- 培训人签字 + 培训人照片（`sign_image` + `photo`）
- 考核试题 + 考核结果（`training_exam`）
- 公司盖章（电子章可配，T12）

## 五、核心流程

### 5.1 岗前培训流程（T5）

```
① 运营方上传线下培训资料（PPT/文档，可下载，企业不传）

② 企业安全员创建岗前培训计划（pre_job）
   选运输类型 + 人员身份 → 系统按学时标准提示（默认仅提示，可开强制开关）
   → 绑定从业人员 → 关联运营上传的线下资料

③ 从业人员在线学习 + 留痕
   在线看视频（记录观看进度）
   + 签字（小程序手写签名）
   + 拍照留痕（上传本人培训照片）
   + 线上考核（题库做题，自动判分）

④ 台账生成
   签字 + 照片 + 考核试题/结果 齐备 → 关联一人一档（07 ref_id）
```

### 5.2 岗中培训流程（T6，运营年度生成）

```
① 服务商账号（平台）每年生成普货/危货两套年度培训计划
   普货：general 年度计划（12 个月视频）
   危货：danger 年度计划（12 个月视频）
   → 12 段视频自动挂入（1~12 月）

② 企业启用计划（安全员确认 + 绑定全员）
   企业选择本年度计划 → 绑定全部从业人员
   → 配置学时开关（默认关闭=仅提示；开启=强制学满才考）

③ 从业人员在线学习 + 留痕
   在线看视频（记录观看进度）+ 签字 + 拍照 + 考核

④ 台账 + 归档
   培训内容 + 签字 + 照片 + 考核结果 → 一键归档盒四
```

> **上月可补学**：岗中培训按月份推进，从业人员可随时补做上月未完成的观看/签字/拍照/考核（无过期作废）。

### 5.3 靶向培训流程（T7/T8，按违规类型随机匹配）

```
① 安全员手动创建靶向专项培训（targeted）
   选择违规类型（从企业自维护的 violation_dict 选）
   → 选择违规人员（绑定）

② 系统随机自动匹配视频（T7）
   按违规类型 → 从视频库筛选带该标签的视频
   → 随机抽取 2 个视频（合计时长 ≤ 30 分钟）挂入

③ 违规人员在线学习 + 留痕
   在线看视频 + 签字 + 拍照 + 考核

④ 台账 + 归档
   与岗中一致
```

### 5.4 考核流程（T4/T9）

```
从业人员进入考核 → 按视频/课程随机抽题组卷
  → 答题（单选/多选/判断）
  → 自动判分 → ≥及格线(默认60)通过，否则可重考(默认3次)
  → 考核试题快照 + 答案 + 结果 留痕
```

> **考核门槛随开关（T9）**：开关关闭=无前置，随时可考；开关开启=须先学满（观看时长达标）才解锁考核。

### 5.5 归档流程（T11/T12/T13/T15，对接 08）

```
培训计划 → 所有从业人员完成（签字 + 拍照 + 考核通过）
  → 安全员归档确认（安全员签字）
  → 主要负责人签字
  → 一键归档到「盒四」
  → 08 生成培训台账 PDF：
     培训内容(视频描述) + 主要负责人签字 + 安全员签字
     + 培训人签字 + 培训人照片 + 考核试题/结果 + 公司盖章(电子章/留空位)
```

## 六、业务规则

1. **三类培训（T1）**：岗前（三级）/ 岗中（年度月度）/ 靶向（违规专项）。
2. **在线学习平台（T2/T3）**：从业人员在系统内在线看视频、做题考核，系统记录观看进度。
3. **学时开关（T9）**：企业可配置，默认关闭（仅提示）；开启则须学满才解锁考核。选择权交给企业。
4. **学习留痕（T10）**：观看进度/时长 + 签字 + 拍照 + 考核结果，全程自动留痕不可改。
5. **题库（T4）**：题目关联视频，做题考核自动判分，试题+结果留痕。
6. **岗前（T5）**：线下资料运营方上传（企业不传），在线学习 + 签字 + 拍照 + 线上考核。
7. **岗中（T6）**：运营年度生成普货/危货 12 个月视频，每月 2 学时随开关决定提示或强制，可补做。
8. **靶向（T7）**：按违规类型手动创建，系统随机匹配 2 个视频（合计 ≤ 30 分钟）。
9. **违规类型（T8）**：只做框架，企业自行维护字典，不预设。
10. **台账要素（T11）**：培训内容 + 三个签字 + 培训人照片 + 考核试题/结果 + 公司盖章。
11. **盖章（T12）**：电子章可配置自动盖，无章图留空位线下盖。
12. **签字（T13）**：培训人签字；安全员 + 主要负责人在归档确认时签字。
13. **不收费（T14）**：一期不做课程缴费。
14. **完成率（T17）**：完成率 = 留痕齐备（签字+拍照+考核通过）人数 / 应学人数，计入企业安全分（权重 20%）。
15. **数据可改、日志不改**：超管可纠错，操作日志全量留存。
16. **归档降级**：有内容/签字/照片/考核就生成对应部分，缺的打印占位（沿用 08 三原则）。

## 十、并发与视频分发架构（1000 人同时观看）

> 这是本模块的**性能关键设计**。线上学习是系统唯一高并发压力点：100 家企业 × 数千司机，最坏情况 **1000 人同时在线看视频**。详见《00-产品定位与架构总纲》6.3。

### 10.1 核心决策：视频走 CDN / 对象存储，源站零压力

| 决策项 | 结论 |
|--------|------|
| 视频存储 | 阿里云 OSS（生产）/ MinIO（私有化本地） |
| 视频分发 | **CDN 边缘节点分发**，用户从最近节点拉流，源站不承载视频流量 |
| 视频转码 | 上传后异步转多码率（1080p / 720p / 480p），适配弱网 |
| 防盗链 | OSS 私有 Bucket + CDN 鉴权（URL 签名带时效），防止盗播 |
| 学习留痕 | 前端定时上报播放进度（心跳），后端记录观看时长，判断是否学完 |

### 10.2 为什么能扛 1000 并发

- **视频是静态大文件**，CDN 边缘节点直接分发，**源站完全不承载视频流量**。
- 1000 人同时看视频，压力分散到 CDN 边缘节点；源站只处理**鉴权 + 播放进度心跳**这类轻量 HTTP 请求。
- 1000 并发的心跳请求 ≈ 1000~2000 QPS 轻量请求，**单机 Spring Boot + Redis 轻松扛住**。
- 数据库压力仅「每秒几次~几十次的学习进度写入」，远低于视频流本身。

### 10.3 容量估算（1000 路 720p）

| 项 | 估算 |
|----|------|
| 单路 720p 码率 | 约 1~1.5 Mbps |
| 1000 路并发带宽 | 约 1~1.5 Gbps（**全部由 CDN 承担**，源站 0 压力） |
| 源站需处理 | 鉴权 + 进度心跳，约 1000~2000 QPS 轻量请求 |
| 存储 | 课程视频预留 OSS 空间（约 500MB/小时，成本极低） |

### 10.4 播放进度留痕（心跳机制）

```
小程序播放器
  → 每 10~30 秒上报一次 { video_id, plan_id, position, duration }
  → 后端写 Redis（进度缓存） + 批量落库（异步）
  → 前端断点续播：从上次 position 继续
  → 学满判定：累计观看时长 ≥ duration（开关开启时）
```

> **关键**：进度上报**异步化**（Redis 缓存 + 定时批量落库），避免 1000 并发心跳直接打库。进度数据最终写 `training_assign` 的 `watch_progress` 字段（见 4.5）。

### 10.5 防盗链与鉴权（URL 签名）

| 步骤 | 说明 |
|------|------|
| 1. 鉴权 | 用户请求视频 → 后端校验登录态 + 是否已绑定该培训 |
| 2. 签名 | 后端生成带时效（如 2 小时）的 OSS/CDN 签名 URL |
| 3. 播放 | 前端用签名 URL 播放，CDN 校验签名，防盗链 |
| 4. 失效 | 签名过期后需重新鉴权获取 |

## 十三、验收标准

1. 支持三类培训：岗前（三级安全教育）、岗中（年度月度）、靶向（违规专项）。
2. 系统是**在线学习平台**：从业人员在系统内在线看视频、做题考核，系统记录观看进度/时长。
3. 学时开关：企业可配置，默认关闭（仅提示，随时可考）；开启则须学满才解锁考核。选择权交给企业。
4. 视频库可上传视频并打"违规类型 + 运输类型"标签，含视频文字描述。
5. 题库支持单选/多选/判断，题目关联视频，能随机组卷、自动判分。
6. 岗前培训：线下资料由运营方上传（企业不传），从业人员完成在线学习 + 签字 + 拍照 + 线上考核。
7. 岗中培训：服务商账号能每年生成普货/危货两套计划 + 12 个月视频，每月 2 学时随开关决定提示或强制，可补做。
8. 靶向培训：按违规类型手动创建，系统随机匹配 2 个视频（合计 ≤ 30 分钟）。
9. 培训台账完整：培训内容（视频描述）+ 主要负责人签字 + 安全员签字 + 培训人签字 + 培训人照片 + 考核试题/结果 + 公司盖章。
10. 一键归档到「盒四·安全生产教育和培训」，归档内容 = 培训计划 + 月度培训（内容+照片+签字）。
11. 培训完成率（留痕齐备率）实时统计，计入企业安全分（权重 20%）。
12. 超管可纠错培训数据，操作日志不可改。
13. **并发验收**：支持 1000 人同时在线观看视频，视频流量由 CDN 承担，源站零视频带宽压力；播放进度心跳异步落库，不阻塞播放。
14. 视频转码：上传后自动转多码率（1080p/720p/480p），弱网自适应。
15. 防盗链：视频 URL 带时效签名，签名过期后需重新鉴权；进度支持断点续播。
