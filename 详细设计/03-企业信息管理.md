# 详细设计 03 —— 企业信息管理

> 版本：v1.0
> 日期：2026-10-27
> 状态：可进入开发
> 说明：企业是平台的顶层概念（租户），所有人员、车辆、制度、台账都挂在一家企业之下。本模块是「一企一档」的主体信息管理。

---

## 一、模块定位

企业信息是平台的**根节点**：

```
企业（租户）
  ├─ 组织架构（部门/岗位/人员）
  ├─ 人员档案
  ├─ 车辆档案
  ├─ 制度档案
  └─ 各类台账（三检/隐患/会议/培训...）
```

本模块只管理企业的**主体资质信息**（营业执照、经营许可、负责人、停车场地等），不涉及人员/车辆的具体档案（那些是后续模块）。

---

## 二、产品决策记录（已确认）

| 决策项 | 结论 |
|--------|------|
| 营运类型 | 货运 / 客运 / 危货（三类） |
| 经营期限 | 长期 / 具体日期 二选一（长期=永久有效，不做过期预警） |
| 集团场景 | **单企业**（一个账号只归属一个企业，不做集团多企业） |

### 2.1 「单企业」对原系统两个模块的影响

原系统有「企业分组」和「企业用户管理」两个菜单，是为**集团多企业**场景设计的（一个集团下管多个子企业）。我们选择单企业后：

| 原模块 | 调整后定位 |
|--------|-----------|
| 企业分组 | **降级为「车队/线路分组」**——不再代表"子企业"，而是企业内部对车辆/人员的分组标签（如"第一车队"） |
| 企业用户管理 | **并入「组织权限」模块的用户管理**——就是给本企业开通登录账号，无集团概念 |

> 结论：这两个菜单不再是"企业级"概念，降级为企业内部的组织单元，具体在「组织架构」模块详细设计。

### 3.2 服务分类字段（服务商视角分组依据）

以下字段由**服务商视角**维护，用于「企业管理」列表的分组与筛选；其中「所在地区 / 运输类型 / 客户分组」企业视角同样可见可编辑，**两侧共用同一份企业档案**（同源字段，非各自独立副本）。注：**「所属服务商」字段仅服务商 / 超管可见，企业视角隐藏**（企业侧不感知其归属的服务商）。

| 字段 | 必填 | 取值 | 说明 |
|------|------|------|------|
| 所在地区（`region`） | ✅ | 佛山 / 广州 / 深圳 / 东莞 / 珠海（可扩展） | 服务商列表的地区筛选依据 |
| 运输类型（`cargo`） | ✅ | 普货 / 危货 | 服务商列表的货类筛选依据 |
| 客户分组（`group`） | ✅ | 重点客户 / 普通客户 / 新签约 | 服务商列表的分组筛选依据，可由服务商自定义扩展 |
| 企业状态（`status`） | ✅ | 正常 / 禁用 | 禁用后该企业全部账号同步禁用，无法登录 |

> **一致性约束**：`region` / `cargo` / `group` / `status` 在「企业管理（服务商视角）」与「企业信息管理（企业视角）」中为**同一份数据**，任一侧修改后另一侧立即同步（原型以 `assets/ent_data.js` 共享数据层 + localStorage 持久化实现；生产环境落 `tenant` 表 + 服务端接口）。

> **模块边界**：「视频库及考题管理」已从企业账号管理中**移出**，作为与服务商「企业管理」**平级**的独立模块（面向其名下所有企业，见 14 培训教育 · 3.4 服务商课程库），企业账号管理只聚焦企业主体、人车档案与待办。

## 四、数据模型

### 4.1 表结构

```sql
-- 企业主体信息（即租户扩展信息）
CREATE TABLE tenant_info (
  id             BIGINT PRIMARY KEY,         -- 与 sys_tenant.id 对应
  tenant_id      BIGINT NOT NULL,            -- 租户ID
  credit_code    VARCHAR(18),                -- 统一社会信用代码
  biz_type       VARCHAR(20) NOT NULL,       -- 营运类型：freight/passenger/danger
  biz_term_type  TINYINT NOT NULL,           -- 经营期限：1长期 2日期
  biz_term_end   DATE,                       -- 经营期限截止（仅当 biz_term_type=2）
  legal_person   VARCHAR(50),                -- 法定代表人
  safety_charge  VARCHAR(50),                -- 安全主要负责人
  charge_phone   VARCHAR(20),                -- 负责人电话
  region         VARCHAR(100),               -- 所在地
  address        VARCHAR(200),               -- 实际经营地址
  industry       VARCHAR(50),                -- 所属行业
  investment     DECIMAL(18,2),              -- 投资总额
  reg_capital    DECIMAL(18,2),              -- 注册资本
  biz_scope      VARCHAR(500),               -- 经营范围
  vehicle_scale  INT,                        -- 车辆规模
  main_route     VARCHAR(200),               -- 主要运输路线（替代原「主营行程」）
  main_cargo     VARCHAR(200),               -- 主要运输货物
  park_location  VARCHAR(200),               -- 停车场地位置（归入 tenant_parking，见下）
  park_area      DECIMAL(10,2),              -- 停车场地面积（归入 tenant_parking，见下）
  safety_staff   INT,                        -- 专职安全员数量
  employee_count INT,                        -- 从业人员数量
  website        VARCHAR(100),               -- 官网
  zipcode        VARCHAR(10),                -- 邮编
  monitor_outsource TINYINT,                 -- 监控外包 1是 0否
  created_at     DATETIME DEFAULT NOW(),
  updated_at     DATETIME
);

-- 企业证照（子表）
CREATE TABLE tenant_cert (
  id          BIGINT PRIMARY KEY,
  tenant_id   BIGINT NOT NULL,
  cert_type   VARCHAR(30) NOT NULL,          -- 营业执照/经营许可证/停车场产权证明/停车场租赁合同/停车场平面图及照片/其它
  cert_no     VARCHAR(50),                   -- 证照编号
  issue_date  DATE,                          -- 发证日期
  expire_date DATE,                          -- 有效期至（预警依据）
  cert_image  VARCHAR(200),                  -- 证照图片（对象存储URL）
  created_at  DATETIME DEFAULT NOW()
);

-- 停车场档案（独立页，一企业一条）
CREATE TABLE tenant_parking (
  id             BIGINT PRIMARY KEY,
  tenant_id      BIGINT NOT NULL,
  address        VARCHAR(200),               -- 停车场地址
  ownership      TINYINT NOT NULL,           -- 所有权：1自有 2租赁
  area           DECIMAL(10,2),              -- 面积（平方米）
  lease_start    DATE,                       -- 租赁期限起
  lease_end      DATE,                       -- 租赁期限止（预警依据）
  land_proof     VARCHAR(200),               -- 土地使用证明（图片URL）
  layout_image   VARCHAR(200),               -- 平面布置图（图片URL）
  lease_contract VARCHAR(200),               -- 租赁协议（文件URL）
  photos         VARCHAR(500),               -- 停车场图片（多图，逗号分隔URL）
  created_at     DATETIME DEFAULT NOW(),
  updated_at     DATETIME
);
```

> **停车场管理（危货盒七）说明（用户确认）**：危货企业档案盒「停车场管理」的 3 个子项——**产权证明、租赁合同、平面图及照片**，属于**企业证件**。系统提供**上传入口留存**（复用 `tenant_cert`，cert_type 扩展停车场相关类型），并做**到期提醒预警**（尤其租赁合同有有效期，纳入 `expire_date` 预警扫描）。仅危货启用，普货隐藏。

### 4.2 预警关联

- `tenant_cert.expire_date` 纳入**预警引擎**扫描（证照到期预警）
- 经营期限：`biz_term_type=1`（长期）**不做过期预警**；`=2`（日期）到期前预警

## 五、页面交互设计（PC 端）

### 5.1 企业信息管理列表页（服务商 / 超管视角）

- 列表：序号、企业名称（含信用代码）、所在地区、运输类型、客户分组、所属服务商、状态、操作
- 筛选：企业名称 / 所在地区 / 运输类型 / 客户分组 / 状态
- 操作：**查看、编辑、禁用（启用）**
- 列表数据与服务商「企业管理」页**同源**，筛选条件与分组标签完全一致

### 5.2 企业信息表单页（页签式）

详情页按**页签**组织，共 4 个页签：

| 页签 | 内容 |
|------|------|
| 企业基本信息 | 基本资料（企业名称、信用代码、成立日期、法定代表人、安全主要负责人、负责人电话、联系电话）、注册与经营范围（所在地、经营许可证、管理类型、**主要运输路线**、**主要运输货物**、经营范围）、服务分类（所在地区 / 运输类型 / 客户分组 / 所属服务商）、规模信息（注册资金、经营面积、停车场面积、专职安全员数量、从业人员数量） |
| 证照信息 | 营业执照 / 道路运输经营许可证 / 安全生产责任险保单等，可上传、预览、到期预警 |
| 材料信息 | **安全评估相关材料**（安全现状评价报告、安全设施设计专篇等）与**许可相关材料**（道路运输经营许可证、安全生产标准化达标证书、应急预案备案登记表等），支持上传 / 下载 |
| 停车场档案 | 停车场**基本信息**（地址、所有权「自有 / 租赁」、面积、租赁期限）+ **佐证材料**（土地使用证明、平面布置图、租赁协议、停车场图片） |

> **本次调整（用户确认）**：
> 1. 删除「上传单位」字段与「行车的主营行程」字段；新增「**主要运输路线**」「**主要运输货物**」两个独立字段。
> 2. 新增「**一键读取天眼查 / 企查查工商信息**」能力：与「上传营业执照 OCR 识别」并列，一键拉取工商公示信息自动填充企业名称、信用代码、成立日期、法定代表人、经营范围、注册资本、管理类型、主要运输路线、主要运输货物等字段（原型为模拟填充，生产接第三方工商数据接口）。
> 3. 「**停车场档案**」由原规模信息中的单字段**独立成页**，承载完整的停车场地信息与佐证材料。
> 4. 删除「岗位轮值图」「作业区域图」两个页签（已不再作为企业主体信息的一部分）。
> 5. 「材料信息」定位为**安全评估 / 许可相关材料**归档，不再混入制度汇编、组织架构图等（那些归入制度文档体系）。

### 5.3 服务商视角「企业管理」页

服务商 / 超管视角下的**企业管理**模块，是「企业信息管理」的**服务商工位形态**，两者共用同一份企业档案。

| 区域 | 内容 |
|------|------|
| 顶部工具栏 | 当前服务商（超管可切换）+ 名下企业数 + **新增企业** + 重置演示数据 |
| 左侧企业列表 | 搜索（名称/信用代码）+ 筛选（地区/货类/分组/状态）+ 分页，适配管理上百家企业 |
| 右侧详情 | 页签：企业信息 / 账号管理 / 合同期 / 功能模块 / 人车管理 / 待办事项 |

**新增企业**

1. 填写：企业名称、信用代码、法定代表人、联系电话、经营类型、所在地区、运输类型、客户分组、所属服务商
2. 保存即生成一条企业档案，并**自动创建企业主账号**（用户名 = 企业名称全称，初始密码 `888888`）
3. 新企业默认开通模块：电子档案柜 / 培训教育 / 考试题库与学习
4. 新增后自动切换到该企业详情，可直接配置合同、模块、人车

**禁用企业**

- 入口：企业详情头部「禁用企业」按钮；列表页也可直接禁用
- 联动：禁用企业 → 该企业**全部账号同步置为禁用** → 「一键登录企业」按钮置灰
- 数据留存：**企业档案、人车档案、合同、台账全部保留**，仅阻断登录入口
- 恢复：同一按钮变为「启用企业」，企业与其账号恢复可用

**修改企业密码**

- 入口：企业管理 → 账号管理 → 账号行「修改密码」
- 规则：新密码 ≥6 位，两次输入一致方可提交
- 效果：仅修改该账号密码；修改后该账号须用新密码登录
- 企业主账号（用户名 = 企业名称全称）的密码同样由服务商在此维护

### 5.4 经营期限交互

```
经营期限：[ 长期 ] 或 [ 具体日期 ]
```

- 选「长期」：不显示日期选择器，该企业不做经营期限到期预警
- 选「具体日期」：显示日期选择器，到期前纳入预警

## 六、状态流转

企业生命周期：

```
待完善 ──完善信息──> 正常 ──到期/违规──> 停用
                       │
                       └── 服务续费 ──> 正常
```

| 状态 | 说明 |
|------|------|
| 待完善 | 企业刚开通，信息未填全 |
| 正常 | 信息完整，正常使用 |
| 停用 | 服务到期 / 被平台停用，禁止登录 |

> 注意：企业「停用」后，该企业所有用户禁止登录（在认证模块已支持，通过 `sys_tenant.status` 控制）。

4. 企业信息表单页（分区块 + 证照上传）
5. 经营期限「长期/日期」二选一交互
6. 证照到期接入预警引擎
7. 超管的企业列表 + 启用/停用

---

## 十、验收标准

1. 企业能完整录入主体信息 + 多张证照（含图片上传）
2. 经营期限选「长期」不产生到期预警，选日期则到期前预警
3. 证照有效期到期前 30 天，首页出现预警
4. 企业被停用后，该企业所有用户无法登录
5. 超管能查看所有企业并停用/启用，普通企业管理员只能看本企业
