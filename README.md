# 道路运输企业安全生产管理平台

> 逆向重构项目 · 原型阶段（本地开发版）

面向道路运输企业（客、货、危运）的安全生产管理平台，包含 **PC 网页端** 和 **微信小程序端**。目标用户是文化水平参差、对电脑/手机不熟悉的运输从业人员，因此设计核心是「功能直给、说人话、大而清晰、颜色表意」。

---

## 一、本地怎么打开

### 方式 A：直接双击（最简单，无需任何环境）

直接双击 `prototype/index.html`，用浏览器打开即可查看全部原型页面。

- 顶部 Tab 可切换「网页端（PC）/ 小程序端」
- 左侧树形菜单导航到 32 个页面

> 说明：原型是纯静态 HTML + CSS + JS，不依赖任何服务器，双击即可离线运行。

### 方式 B：起个本地静态服务（可选，体验更接近线上）

如果你想用 `http://localhost` 的方式访问（某些浏览器对 `file://` 有 iframe 限制时可选用）：

```bash
cd prototype
python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080
```

## 四、技术选型（已确认，见需求文档）

| 层 | 选型 |
|----|------|
| 后端 | Spring Boot 3 + MySQL 8 + Redis |
| 前端（PC） | Vue 3 + Element Plus |
| 前端（小程序） | uni-app |
| 认证 | 统一 SSO（账号密码 + 图形验证码） |

> 选型标准：**易扩展、易新增功能**，非复刻原系统的 Java + layui。

## 五、设计规范速查（design system）

| 项 | PC 端 | 小程序端 |
|----|-------|----------|
| 风格 | Data-Dense Dashboard | Accessible & Ethical（适老化） |
| 主色 | 深蓝 `#1a5cb0` | 醒目橙 `#ff7a00` |
| 正文对比度 | ≥ 4.5:1 | ≥ 4.5:1 |
| 字号 | 正文 15px | 正文 ≥ 17px |
| 触控热区 | 按钮 ≥ 36px | 按钮 ≥ 48px |
| 图标 | SVG（Lucide 风格，`assets/icons.js`） | 同左 |

语义色约定：**绿=正常 `#1a9e50` · 橙=注意 `#e88600` · 红=紧急 `#d92b2b`**
