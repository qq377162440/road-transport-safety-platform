# 用户手册 · 企业版

> 适用对象：运输企业负责人、安全员、驾驶员、资料员
> 版本：v1.0.0-prod（E3）
> 系统入口：由服务商提供的域名（HTTPS），例如 `https://safetrans.example.com`

---

## 1. 登录与账号

| 账号类型 | 账号来源 | 初始密码 | 说明 |
|---|---|---|---|
| 企业主账号 | 服务商开户时生成，**用户名 = 企业全称** | `888888` | 首次登录请立即修改 |
| 安全员 / 驾驶员 | 在人员档案录入**手机号**时自动开通 | `123456` | 账号 = 手机号，岗位决定可见功能 |
| 平台演示账号 | `aa_gaozhou` / `123456` | 仅演示环境 | 生产环境不提供 |

**首次登录必做**：右上角菜单 → 修改密码（新密码需 ≥ 8 位且同时含字母和数字）。改密后旧登录态立即失效，需重新登录。

> 账号身份由系统按 `sys_user.user_type` 判定：驾驶员（`driver`）登录后只看到与三检、报修、学习相关的功能；企业主账号（`enterprise`）可看到全部企业管理功能。

## 2. 首次接入：三步填报

服务商开户后，用主账号登录，访问 **`/m/onboard`**（也可由服务商发送带登录态的链接）。未完成前三步时，业务功能处于锁定状态，系统只显示接入引导。

| 步骤 | 填写内容 | 系统自动做什么 |
|---|---|---|
| ① 企业资料 | 法定代表人、安全主要负责人、负责人电话、所在地区、地址、人员规模、车辆规模 | 写入企业信息档案，标记「营业执照」检查项 |
| ② 人车档案 | 人员姓名 + 手机号 + 岗位；车牌号 + 车辆类型 | **按手机号自动开通小程序账号**，人档车档自动登记归档项 |
| ③ 安全现状 | 4 个选择题（是否有制度/预案/培训记录/台账齐全）+ 补充说明 | 生成现状诊断，驱动服务商确定整改范围 |

点「提交，完成接入」后业务功能解锁，进入阶段 2「静态资料全面整改」。页面为大字号、大按钮设计，手机上可直接操作。

## 3. 企业信息管理（`/company`）

维护统一社会信用代码、营运类型、经营期限、法定代表人、安全主要负责人、所属地区、从业人员与车辆规模等。接入三步填报只要求必填项，其余字段在这里补齐。

## 4. 安全管理架构与岗位（`/org`、`/post`）

- **组织架构**：维护领导小组与岗位层级，总经理为根节点。
- **岗位信息管理**：启用/禁用岗位、修改岗位名称。系统内置 12 类职能（总经理、安全员、监控员、驾驶员等）。
- **强制岗位**（打 `*` 号）：总经理、安全员、监控员为必设岗位，**禁用会被系统拦截**。
- **改名联动**：修改岗位名称后，「安全生产责任制」中引用该岗位的内容会自动同步，无需逐份修改制度文件。

## 5. 范本套与安全生产责任制（`/template-manager`、`/responsibility`）

- 服务商提供范本套（普货通用 / 小微 / 危货），企业选择并设为默认。
- **安全生产责任制**：按已启用的岗位生成，包含安全目标、职责、考核标准；生成后自动归档到「盒二」。
- 制度文件需盖章/签字时，用「自定义文件签署」（见 `业务闭环工具箱`）拖拽锚点后合成 PDF。

> 责任书、承诺书、职业病危害告知书按**自然年度（每年 1 月 1 日）重签**，到期前系统会预警。

## 6. 一日三检（`/m/check`）—— 验收标准 ①

面向不会用电脑的中老年司机，只有三步：**选任务 → 选时段（出车前/行车中/收车后）→ 点「合格」或「异常」**。

- 全大字号、大按钮、高对比；点「异常」可填写说明，系统自动联动生成隐患记录。
- 目标：**30 秒内独立完成一次三检**。
- 三检明细不装盒，系统按月汇总生成**三检月报**并归档。

## 7. 隐患排查治理（`/biz/danger` + `/flow-tools`）

闭环三步：登记 → 整改下发 → 验收。

1. 隐患可由三检异常自动产生，也可手工登记。
2. 安全员填写整改要求，状态变为「整改中」。
3. 整改完成后验收，状态变为「已闭环」；记录自动归档。

## 8. 安全会议（`/biz/meeting` + `/flow-tools`）

四段式留痕：会议通知 → 签到 → 会议记录 → 现场照片。每完成一段都会沉淀归档项，季度/月度会议可一键生成整套台账。

## 9. 电子档案柜（`/archive`、`/archive-overview`）—— 验收标准 ②

- 目录按营运类型区分：**普货 10 盒 / 危货 11 盒**，盒内按二级子项分组。
- **全景与缺项**页用红黄绿标示缺项，支持批量生成待归档项与整套 PDF 下载。
- 目标：政府检查时 **5 分钟内调出完整台账**。
- 服务商侧可用「归档就位自检」逐项核对：档案盒目录、归档项、人员/车辆档案、制度归档、检查项进度。

## 10. 培训教育（`/biz/training`、`/flow-tools`）

培训计划 → 课程下发 → 视频学习（学时上报）→ 在线考试（分数留痕）→ 学时统计。岗前培训考核合格方可上岗；课程库由服务商维护。

## 11. 风险可视驾驶舱（`/risk-dashboard`）—— 验收标准 ③

展示企业安全分与**当前最紧急的安全风险**，老板登录首页即可看到，无需翻台账。安全分由缺项、隐患闭环率、培训完成率等计算。

## 12. 试运行反馈（`/feedback`）

使用中遇到问题：选择模块 → 类型（缺陷/建议/表扬/咨询）→ 严重程度 → 填写内容 → 提交。平台受理后会给出处理说明；可在列表查看状态（待受理 / 处理中 / 已解决 / 已驳回）。企业只能看到本企业的反馈。

## 13. 常见问题

| 问题 | 处理 |
|---|---|
| 忘记密码 | 联系服务商/平台重置（当前版本无自助找回，已列入后续迭代） |
| 手机号填错导致账号开错 | 在人员档案修正后联系平台停用旧账号；人档车档保留 ≥ 3 年 |
| 岗位改了但责任制没变 | 责任制需重新生成一次；生成时读取当前启用岗位名称 |
| 档案柜显示缺项 | 到对应业务模块补录记录，或由服务商在代录工作台批量补齐 |
| PDF 打开是黑体不是宋体 | 当前 PDF 引擎使用文泉驿正黑 TTF（PDFBox 2.0.24 不支持 CFF/OTF 子集化），属已知技术约束 |
| 登录后提示「登录已失效」 | 修改密码或令牌过期（2 小时），重新登录即可 |

## 14. 四条验收标准 · 操作速查卡

| 标准 | 谁来做 | 路径 | 判定 |
|---|---|---|---|
| ① 30 秒完成一次三检 | 驾驶员 | `/m/check` | 三步点完，页面给出结果提示 |
| ② 5 分钟调出完整台账 | 安全员 | `/archive-overview` → 全景/缺项 → 批量下载 | 整套台账 PDF 可下载 |
| ③ 一眼看出最紧急风险 | 老板 | `/risk-dashboard` | 首页显示安全分与最紧急风险 |
| ④ 小微个体户快速补齐台账 | 服务商 | `/collect` 代录工作台 | 复用历史签字、跳过推送直接落业务表 |

> 需要人工协助时，在 `/feedback` 提交反馈并留下联系方式。
